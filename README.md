# Portfolio Web - William PRAT

## 📋 Description

Portfolio professionnel moderne et minimaliste pour William PRAT, Technicien Supérieur Systèmes & Réseaux. Le site présente son profil, ses compétences, sa stack technologique et offre un moyen de le contacter.

## 🎨 Caractéristiques

- **Design Minimaliste Moderne** : Interface épurée et élégante
- **Responsive** : Adapté à tous les appareils (mobile, tablette, desktop)
- **Animations fluides** : Transitions et animations CSS3 pour une meilleure expérience utilisateur
- **Performance optimisée** : Chargement rapide et optimisé
- **Accessibilité** : Conforme aux standards web

## 🚀 Comment utiliser

### Installation locale

1. Clonez ou téléchargez ce projet
2. Ouvrez le dossier dans votre éditeur favori (VS Code, etc.)
3. Ouvrez `index.html` dans votre navigateur

### Déploiement

Pour mettre votre portfolio en ligne :

1. **GitHub Pages** (Gratuit)
   - Créez un repository GitHub
   - Uploadez les fichiers
   - Activez GitHub Pages dans les paramètres

2. **Netlify** (Gratuit)
   - Rendez-vous sur [netlify.com](https://netlify.com)
   - Connectez votre repository ou uploadez les fichiers
   - Votre site est en ligne !

3. **Hébergement traditionnel**
   - Uploadez les fichiers via FTP/SFTP sur votre serveur

## ✏️ Personnalisation

### Informations personnelles

Modifiez `index.html` :

```html
<!-- Ligne 7 : Titre de la page -->
<title>Votre Nom | Votre Titre</title>

<!-- Ligne 16 : Logo de navigation -->
<div class="logo">VN</div>

<!-- Lignes 23-26 : En-tête principal -->
<h1>Votre Nom</h1>
<p class="subtitle">Votre Titre</p>
```

### Couleurs et styles

Modifiez les variables CSS au début de `styles.css` :

```css
:root {
    --primary-color: #1a1a1a;      /* Couleur primaire (texte)*/
    --secondary-color: #ffffff;    /* Couleur secondaire (fond)*/
    --accent-color: #0066cc;       /* Couleur d'accent (boutons)*/
    --text-color: #333333;         /* Couleur du texte */
    --light-bg: #f8f9fa;           /* Fond clair */
}
```

### Contenu des sections

Chaque section (À propos, Compétences, Technologies) peut être modifiée directement dans `index.html`.
